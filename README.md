# Tic-Tac-Toe 🎮

A simple, responsive and attractive Tic-Tac-Toe game built with Vanilla JavaScript.

**Live Demo:** https://vaibhav-sri09.github.io/Tic-Tac-Toe/

![Game Preview](https://github.com/Vaibhav-sri09/Tic-Tac-Toe/blob/main/preview.png?raw=true)

### ✨ Features
- 2 Player gameplay (X vs O)
- Winning detection & highlight
- Reset & New Game
- Responsive for mobile & desktop
- Clean dark gradient UI with hover effects

### 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Gradients, Glassmorphism)
- Vanilla JavaScript (No frameworks)
